# ha-tv-kit · packages the debloat scripts REFUSE to disable.
# Each line is a substring: any package whose name contains it is protected.
# Disabling these can stop the TV booting, break HDMI inputs, the remote, casting, the keyboard, updates,
# adb, Home Assistant's control of the TV, or TV Kiosk.
# Add your own vendor's critical packages here. Don't remove lines unless you know exactly why.
